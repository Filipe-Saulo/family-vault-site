Política de privacidade do family-vault

Última atualização: 10 de novembro de 2026.

Quem usa

O family-vault é um aplicativo pessoal de controle financeiro, usado por um grupo pequeno de pessoas conhecidas. Não é vendido nem oferecido ao público.

Dados do Google que o app acessa

Só quando o usuário conecta a própria conta do Gmail, e com o consentimento dele, o app usa o escopo gmail.readonly para ler a caixa de entrada. A leitura é limitada a e-mails com PDF e termos de cobrança (boleto, fatura, vencimento, segunda via). O Gmail é lido no momento da conexão e quando o usuário pede, nunca em rotina automática. O app não envia, apaga nem altera e-mails.

Como os dados são usados

  • O PDF da cobrança é interpretado para extrair emissor, valor, vencimento e código de barras, e o resultado é mostrado ao usuário como uma sugestão.
  • Só a confirmação do usuário cria a despesa. O PDF não é guardado depois de processado.
  • A autorização do Google é guardada criptografada e serve apenas para essa leitura.
  • Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.
  • O uso de dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar

O usuário pode desconectar o Gmail no próprio app ou revogar o acesso a qualquer momento em myaccount.google.com/permissions. Ao desconectar, a autorização guardada é apagada.
